# 免费矢量地图 → CAD 工具

把地图上框选的一块区域，变成 **GeoJSON 矢量文件 + AutoCAD 能直接打开的 DXF 图纸**。

- 不需要高德/百度地图的 Key，**不花钱、不限次数**
- **国内可直连**（走 OSM 官方接口 + 公共矢量瓦片兜底，无需翻墙）
- 数据来自 [OpenStreetMap](https://www.openstreetmap.org/)（全球最大的免费开放地图）
- 输出**真矢量**：建筑物是闭合多段线，道路是有宽度的中心线，可量尺寸、可编辑、可打印

---

## 快速上手

### 方法一：Windows 一键启动（推荐小白）

如果你用的是 Windows，直接下载仓库里的 `启动工具.bat` 所在的**整个文件夹**，双击 `启动工具.bat` 即可（会自动安装依赖并打开页面）。

### 方法二：命令行启动（任意系统）

```bash
# 1. 安装依赖（只需一次）
pip install -r requirements.txt

# 2. 启动工具
python server.py
```

启动后浏览器会自动打开工具页面，按页面上的 **1 → 2 → 3 → 4** 四步操作即可。

生成的 `.geojson` 和 `.dxf` 文件都在 **`output`** 文件夹里。
